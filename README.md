# My Website

I made this website to describe me.

## Tech Stack

| Technology | Purpose |
| --- | --- |
| [Astro](https://astro.build/) | Website framework and build tooling |
| [React](https://react.dev/) | OG Image and Discord component generation |
| [Lenis](https://lenis.dev/) | Smooth scrolling |
| [Inter](https://fonts.google.com/specimen/Inter) | Typography, self-hosted with Fontsource |
| [Satori](https://github.com/vercel/satori) | SVG image generation |
| [Sharp](https://sharp.pixelplumbing.com/) | Image processing |
| [Prettier](https://prettier.io/) | Code formatting, including Astro files |
